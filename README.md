# Using-LLM-to-extract-information-from-texts

Тема:

Применение LLM для извлечения информации из текстов

Цель проекта:

Разработка программной системы, использующей большие языковые модели (LLM) для автоматического извлечения заданной структурированной информации из неструктурированных текстов.

Основные задачи:

Исследовать существующие методы извлечения информации из текстов.
Исследовать возможности современных LLM для решения задачи.
Сформировать и подготовить набор тестовых данных.
Разработать прототип системы извлечения информации.
Исследовать различные подходы к формированию запросов и структурированию ответа LLM.
Разработать методику оценки качества извлечения.
Провести экспериментальное сравнение подходов.
Реализовать API и пользовательский интерфейс.
Провести тестирование и анализ ошибок.
Подготовить документацию и итоговые материалы проекта.
